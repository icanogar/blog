# Los estímulos reunidos
## un registro del asombro cotidiano

es mi blog personal sobre cosas sensacionales. Está construido en [Jekyll](https://jekyllrb.com/) con la potente y flexible plantilla [Centrarium](https://github.com/bencentra/centrarium) de [Ben Centra](http://bencentra.com), a la que he añadido comentarios a través de [Talkyard](https://blog-comments.talkyard.io/). Se publica en Github Pages a través de [jekyll-archives](https://github.com/jekyll/jekyll-archives), un plugin un poco delicado que obliga a la construcción del sitio en local. También incorpora otro, [jekyll-target-blank](https://github.com/keithmifsud/jekyll-target-blank), que permite que los links en Markdown se abran en pestaña nueva. Si tienes un conocimiento mínimo de estas herramientas, en un par de tardes puedes tener un blog similar, ajeno a los vaivenes de las grandes corporaciones... ¡y virtualmente indestructible!
